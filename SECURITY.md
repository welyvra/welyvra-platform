# Security policy

Welyvra is pre-alpha and not deployed in production. It has not been externally audited.

## Reporting a vulnerability

Please **do not** open a public issue. Use GitHub's private vulnerability reporting: **Security → Report a vulnerability** on this repository.

Include the affected component, steps to reproduce, and impact. We aim to acknowledge reports within 5 business days. There is no bug bounty at this time.

## Scope

In scope: anything in this repository, especially issues that could cause a deposit to be lost, double-counted, attributed to the wrong customer, or exposed across tenants.

Out of scope: Stellar network or SDK vulnerabilities (report them to the [Stellar Development Foundation](https://stellar.org/grants-and-funding/bug-bounty)).
